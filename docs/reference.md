# 能力参考

本文记录 Signal `0.1.4` 当前代码所支持的来源、协议、数据范围和限制。

## 数据源

| 来源 | 默认同步 | 默认订阅 | 间隔 | 登录 | 当前数据范围与限制 |
|---|---:|---:|---:|---|---|
| Hacker News | 开 | 开 | 30 分钟 | 不需要 | Top Stories 前 50 条；Ask/Show HN 缓存 `text`，普通外链在页面存在可识别正文区域时按需缓存 |
| GitHub Trending | 开 | 开 | 60 分钟 | 不需要 | 使用匿名 Search API，取近 7 天新建且 Star 排名前 25 的仓库；不是 GitHub 网页 Trending 算法，受匿名 API 限流影响 |
| V2EX | 开 | 开 | 30 分钟 | 不需要 | 热门主题 API；接近限流阈值时跳过本轮，可缓存主题正文 |
| 掘金 | 开 | 开 | 20 分钟 | 可选 Cookie | 公开推荐流最多请求 3 页、每页 20 条；正文依赖公开详情接口和上游响应结构 |
| 知乎热榜 | 开 | 开 | 20 分钟 | 可选 Cookie | 热榜最多 50 条；原文页面存在可识别正文区域时按需缓存，否则保留来源摘要和原文入口 |
| CSDN 热榜 | 开 | 开 | 30 分钟 | 不需要 | 热榜最多 50 条；正文从文章页面元素提取，页面结构变化时可能失败 |
| 力扣讨论 | 开 | 开 | 30 分钟 | 不需要 | 中国站 GraphQL 热门讨论；仅接收最近 30 天结果，并在原文页面可解析时缓存正文 |
| Reddit `r/programming` | 关 | 关 | 60 分钟 | 当前不支持登录 | Hot JSON 最多 50 条；匿名请求在部分网络或上游策略下返回 HTTP 403，因此默认关闭 |
| Rust 官方博客 | 开 | 开 | 120 分钟 | 不需要 | 读取官方 RSS；按原文页面可识别正文区域缓存内容 |
| 用户 RSS/Atom | 用户添加 | 开 | 60 分钟 | 不支持 | 可选择内置技术社区预设或手动填写名称与 Feed URL；添加前验证真实 Feed，普通网页不能作为 Feed 添加 |

同步间隔可设为 1 到 1440 分钟。应用启动时所有已启用来源会立即请求一次。来源适配依赖第三方公开接口或页面结构，不构成可用性承诺。缺少发布时间的新内容使用本轮采集时间；重复文章同步时会更新来源元数据。

用户 Feed 的内置预设包括 SegmentFault、OSCHINA、博客园、Ruby China、InfoQ 中文、DEV Community、Lobsters、Rust Users Forum、Rust Internals、Python Discussions 和 Go Forum。选择预设只会填入名称和 URL，仍需用户点击“添加”，并通过实时 RSS/Atom 校验后才保存。

Product Hunt 当前未注册。其匿名访问、凭据和限流要求尚未形成可发布的来源适配，因此界面中不能启用它。

## AI 协议

| Provider ID | 生成协议 | 连接验证 | 鉴权 |
|---|---|---|---|
| `openai-compatible` | `POST .../chat/completions` | 查询指定模型并执行最小 JSON 生成 | `Authorization: Bearer` |
| `anthropic` | `POST .../v1/messages` | 查询指定模型并执行最小 JSON 生成 | `x-api-key` 和 Anthropic 版本头 |
| `gemini` | Gemini `generateContent` | 查询指定模型并执行最小 JSON 生成 | `x-goog-api-key` |
| `ollama` | `POST .../api/chat`，非流式 JSON | `POST .../api/show` 并执行最小 JSON 生成 | 无 |

AI 请求超时为 120 秒。文章洞察发送标题、来源、作者，以及最多 24,000 个字符的缓存正文；没有正文时发送来源摘要。结果必须能解析为包含摘要的 JSON。文章思维导图同样只在用户手动生成时发送当前文章的缓存正文或来源摘要，最多 24,000 个字符；模型返回 1 到 40 个节点及其关系后，Signal 才会保存结果。

AI 搜索先使用 SQLite FTS5 检索全库命中内容，再合并最多 80 篇近期文章并去重，最终向模型发送最多 100 个候选的 ID、标题、来源和摘要摘录。模型最多返回 8 个相关 ID，并可补充稳定背景知识，但必须区分本地证据与模型知识。当前不接入独立互联网搜索引擎：它不保证覆盖未采集网页、刚发生事件、登录内容或实时数据；模型不得虚构实时事件、URL 或引用。

默认开启人工审核。洞察状态包括待处理、草稿、已接受、已拒绝和失败；草稿可编辑后接受。自动化测试覆盖四类协议的 URL、请求体和响应解析，但不使用真实云 Key 发起模型调用，也不要求本地 Ollama 在线。

## 本地工作区

| 工作区 | 选择规则 |
|---|---|
| 首页 Dashboard | 本地最近 24 小时抓取的文章，按抓取时间倒序 |
| 热门趋势 | 最近 3 天 Top20 话题，按标题/摘要中的真实技术关键词匹配文章数排序 |
| 我的订阅 | 来自已订阅来源的文章 |
| AI 摘要 | 按待处理、草稿、已完成状态查看 AI 洞察 |
| 稍后阅读 | 已标记稍后阅读的文章 |
| 收藏知识库 | 已加入知识库的文章和笔记入口 |

全文搜索基于 SQLite FTS5 的标题、摘要和已缓存正文。多个搜索词按 AND 组合；最多返回 100 条并按热度排序。关键词黑白名单匹配标题与摘要，不区分大小写。

## 数据保留

- 普通文章在成功同步后的清理中保留最近 7 天，并限制每个来源最多 1000 条。
- 已收藏、稍后阅读或加入知识库的文章不受上述自动清理影响。
- 正文只在来源能够提供且用户打开文章请求到内容后缓存；当前配置中的全量预抓取开关没有用户界面和调度实现。
- 每篇文章最多保存一份 AI 思维导图。重新生成会原位覆盖旧结果；含有思维导图的文章不会被普通的自动清理删除。
- 热度趋势来自本地抓取时保存的快照，阅读量来自本地打开记录，不是来源站点的完整统计。

## 已知限制

- 官方发布构建 Windows x64、macOS Intel、macOS Apple Silicon 和 Linux x64；没有移动端发布包。
- 当前安装包未签名；每个版本附带 `SHA256SUMS`，用于校验文件完整性但不能替代平台代码签名。
- 第三方来源可能限流、返回 403、要求登录或修改接口；Signal 不绕过访问控制。
- “离线阅读”只覆盖页面存在可识别正文区域且抓取成功的内容；登录墙、脚本渲染或结构变化时仍需打开原文。
- 来源 Cookie 和 AI API Key 均保存在操作系统凭据存储中；旧版明文来源 Cookie 会在启动时迁移并从 `settings.json` 清除。
- AI 结果依赖用户选择的模型和兼容端点，可能失败或产生错误内容，接受前应核对原文。
- 思维导图不是知识图谱或多人协作功能，不支持导出、版本历史或手动编辑节点；重新生成前请确认不需要保留旧结果。
- OpenAI Compatible 支持标准 Chat Completions、常见文本分段、SSE 和 Responses 风格文本字段；中转服务仍必须返回可读取文本并允许模型生成 JSON 对象。
